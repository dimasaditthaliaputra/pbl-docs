## Apa itu PAGORA?

**PAGORA** adalah sistem pengadaan (_procurement_) berbasis web yang dibangun dengan arsitektur **monolith**: Laravel dan React berjalan dalam **satu project** (bukan repositori terpisah), dijembatani secara elegan oleh **Inertia.js**.

<Callout type="info" title="Arsitektur Monolith">
  PAGORA bukan aplikasi dengan backend API terpisah dan Single Page Application (SPA) mandiri.
  Controller Laravel langsung me-render halaman React menggunakan <code>Inertia::render()</code>{' '}
  tanpa perlu membangun endpoint REST API untuk alur halaman biasa.
</Callout>

## Stack Teknologi

Tabel berikut merangkum seluruh fondasi teknologi utama yang digunakan dalam pengembangan sistem PAGORA:

| Item                   | Keterangan                                                                                                  |
| ---------------------- | ----------------------------------------------------------------------------------------------------------- |

| **Modul referensi**    | `Komoditas` (CRUD lengkap, dipakai sebagai contoh pola arsitektur)                                          |

## Bagaimana Inertia.js Bekerja?

Inertia.js bertindak sebagai **jembatan** antara backend Laravel dan frontend React:

- Controller Laravel me-render halaman React lewat `Inertia::render('Path/Komponen', $props)`.
- Pengembang tidak perlu membangun API terpisah (seperti Laravel API Resource routes) hanya untuk menampilkan halaman biasa.
- Header `X-Inertia` dikirim secara otomatis oleh Inertia pada request XHR, bersama token CSRF.
- Endpoint JSON murni hanya dipakai untuk kebutuhan khusus (misalnya fitur _async search_ pada Combobox).

## Modul Referensi: Komoditas

Seluruh pola arsitektur, alur data, form, dan standar kode di PAGORA mengacu pada modul referensi **Komoditas**. Modul ini telah mengimplementasikan alur CRUD lengkap:

- Listing data dengan TanStack Table server-side (pencarian, pengurutan whitelist, dan paginasi).
- Form tambah data (`Create.jsx`) dan form ubah data (`Edit.jsx`) yang memanfaatkan form reusable (`KomoditasForm.jsx`).
- Validasi Form Request dengan pesan Bahasa Indonesia.
- Identifier publik UUID dan API Resource eksplisit (`KomoditasResource.php`).
