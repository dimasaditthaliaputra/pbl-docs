## Gambaran Umum

Halaman ini menguraikan struktur folder backend Laravel (`app/`) dan frontend React (`resources/js/`) pada proyek PAGORA.

## Backend (app/)

Struktur folder backend mencakup Helpers, Controllers, Requests, Resources, Models, Repositories, dan Services.

## Frontend (resources/js/)

Struktur folder frontend mencakup Pages, Layouts, Components, dan lib.
