## Gambaran Umum

Halaman ini menguraikan arsitektur backend PAGORA yang menerapkan kombinasi MVC dan Service Repository Pattern.

## Alur Request

Alur request mengalir dari Route menuju Controller, Service, Repository Interface, hingga Model dan Database.

## Tanggung Jawab Layer

Masing-masing layer memiliki tugas terpisah: Controller tipis, Service menangani transaksi dan logika bisnis, dan Repository menangani akses data.
