## Gambaran Umum

Panduan resmi tata kelola Git untuk tim pengembang dan AI agent yang berkontribusi pada proyek PAGORA.

## Aturan Branch dan Commit

Standar pembuatan branch berbasis prefix (`feat/*`, `fix/*`, `refactor/*`, `docs/*`, `chore/*`) dan format pesan commit berjarak spasi (`feat : ...`).

## Alur Kerja dan Pull Request

Tata cara sinkronisasi kode dari main, mitigasi konflik dengan stash dan merge, serta ketentuan persetujuan PR oleh pemilik repositori.
